01 Mindle
Shipped

Mindle

Markdown comment collaboration for Mindle, a quiet place to read Markdown.

What it does

A native macOS e-reader for Markdown files, with highlighting, annotations and full GitHub Flavored Markdown support. Files open the way a book does: one column, no chrome, nothing to configure before reading.

Why I built it

Markdown lives in editors, and editors are built for writing rather than reading. Mindle exists to give long documents somewhere calm to be read.

02 Puffer Properties
Shipped

Puffer Properties

A multi-agent property acquisition system.

What it does

Puffer runs a multi-agent acquisition system. Every listing we consider is sifted, graded for condition, modelled for cost and yield, and given a verdict against fixed targets — before anyone looks at it.

Why I built it

Acquisition decisions stall on the same repeated analysis. Making the sift, the grade and the model automatic leaves only the judgement call.

06 GPX Exporter
Shipped

GPX Exporter

Paste a Strava or Komoot URL and download the GPX file.

What it does

Strava, Komoot and Garmin make it surprisingly hard to get a plain GPX file out. GPX Exporter takes a URL from any of these services and hands back a downloadable GPX — no clicking through menus, no premium tier required for basic exports.

Why I built it

Every time I wanted to share a route or load it into another app, the export was buried three menus deep or locked behind a paywall. One URL in, one file out.

About

Approach

Every project here is built quickly and deliberately kept small. They were designed to automate or fix items in daily life, so we can spend more time on things that matter.
