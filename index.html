04 Inaugural Parkrun
Shipped

Inaugural Parkrun

A Cloudflare Worker that detects new parkrun events by comparing weekly snapshots, then emails subscribers a personalised distance-sorted report.

What it does

Every Friday evening a scheduled Cloudflare Worker fetches the full parkrun events list, compares it against the previous week's snapshot, enriches new entries by scraping each event page for inaugural status, then emails every subscriber a personalised report sorted by distance from their postcode. The web page at inauguralparkrun.naiklabs.dev shows the latest scan results and lets visitors subscribe.

Why I built it

Inaugural events are announced in scattered places. One scheduled job collects them into a single answer: which parkruns are about to launch, and how far away are they from me.

07 Crossword Generator
Shipped

Crossword Generator

AI-powered crossword puzzles on any topic. Type a theme, get a playable puzzle in seconds.

What it does

Enter any topic — Premier League transfers, space exploration, cooking — and the app generates a full crossword puzzle with themed words and clues. The grid algorithm scores and places words with strict adjacency rules, then crops to fit. Every puzzle gets a shareable URL, and the whole thing runs with keyboard navigation, a timer, scoring, hints, and dark mode.

Why I built it

A learning project that touches a lot of the stack: Docker containerisation, Cloudflare Tunnel routing to a local deployment, hot-swapping between LLM providers (Gemini, Claude, open-source endpoints), and Google Search grounding to prevent hallucination on current-events topics. Crosswords are also a good stress test for structured LLM output — the model has to produce interlocking words that fit a grid, not just prose.

Key features

LLM provider switching (Gemini, Claude, mock) • Google Search grounding for factual topics • Shareable puzzle URLs • PNG export with clues • Keyboard navigation • Timer and scoring • Dark mode • Pre-built demo puzzles as fallback • Admin analytics dashboard
